# FF14 潛水艇配裝與海域掉落查詢

V2.0 繁體中文靜態單頁網站。提供部件配裝、等級與負重檢查、航點解鎖紀錄、掉落搜尋與分類查詢。
目前沒有多點航線、航行耗時或收益最佳化算法。

## 使用

直接開啟 `index.html` 即可使用；Vue、CSS 與海圖都隨專案提供，執行不需 CDN、後端或 npm。
設定潛艇等級、選擇四個部件，或使用預設配裝。航點第一次點擊解鎖、第二次鎖定掉落檢視、第三次取消。
搜尋掉落物後按 Enter，或使用分類道具選單即可跳轉海圖。

配裝、等級、海域與解鎖進度會儲存在目前瀏覽器的 localStorage；不會上傳或跨裝置同步。
瀏覽器禁止儲存時仍可操作，頁面會顯示無法保存的狀態。本機檔案與正式網址的存檔各自獨立。
初次開啟不預填已解鎖進度。

航點名稱預設只顯示滑過、鍵盤聚焦或正在檢視的航點，可勾選「顯示所有航點名稱」。
小螢幕可左右滑動海圖；航點支援 Tab 聚焦及 Enter／空白鍵點選。

## 發布到 GitHub Pages

1. 將專案提交至 GitHub 儲存庫。
2. 在 **Settings → Pages → Build and deployment** 選 **Deploy from a branch**。
3. 選擇網站所在分支（例如 `main`），資料夾選 **/(root)**，儲存並等待部署。
4. 以 Pages 網址驗收海圖、搜尋與存檔。所有資源均為相對路徑，可部署於專案子路徑。

`index.html`、`assets/` 與 `submarine-maps/` 是執行必要檔案；已提交的 CSS 可直接使用，不需線上建置。
從根目錄發布也會公開 `legacy/` 和文件。發布前仍需確認海圖與資料的使用條件及選定程式碼授權。

## 維護與建置

```text
index.html        唯一正式入口，包含 Vue 邏輯、頁面樣式與資料
assets/           預先編譯的 CSS、本地 Vue 與套件授權
submarine-maps/   七張海圖
styles/input.css  Tailwind 編譯入口
scripts/build.mjs 重建 CSS 與本地套件資源
data/             計算核對用遊戲資料快照、來源與雜湊
tests/            計算、存檔驗證與資料一致性測試
legacy/           歷史檔案，不參與正式頁面執行
```

編輯 `index.html` 後，若增加 Tailwind 類別，執行以下指令並一併提交 `assets/` 的變更：

```sh
npm ci
npm run build
npm test
```

依賴版本固定於 `package.json`／`package-lock.json`。正式頁面不執行 npm。
遊戲資料目前內嵌於 `index.html`，`data/` 是此次核對快照；更新時需同步資料與測試，並記錄來源日期。
請勿直接執行 `legacy/` 的生成器，它們可能覆寫新版且包含歷史錯誤公式。
